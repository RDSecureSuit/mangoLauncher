# Change log

### Fixed

- Se corrigió un problema en el teclado Mac, el cuál invocaba la tecla ESC en ves de Cap Lock
- Se eliminaron las referencias a los antigüos `jnlp`, ahora las librerias `.jar.pack.gz` ya no son necesarias

- Se integraron las nuevas librerías del Cliente basadas en RDSecure, lo cuál reemplaza algunos nombres nativos de HOB por RDS
- Soporte para HOBLink JWT 1.4.0001, el cuál tiene una mejora sustanciañ en el manejo de RDP

### Improved

- Se mejoró el script `launch.command` el cuál ahora lee la información de la licencia y certificados directamente desde la url, sin necesidad de de3scargarlos primero.
