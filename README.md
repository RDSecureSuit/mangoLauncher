# mangoLauncher - RDS Client for Mac

Esta es una implementacón del cliente Jlaunch.

## Versiones soportadas

- **HOB RD VPN 2.2 en adelante**
- **RDSecure 2.5**, **RDSecure myCloud 1.0**

## Requisitos

- Java 21.0.7 +
- Conexión al servidor de HOB/RDSecure
